КТ «Живой уровень для питча» — готовые скрипты
==============================================

ЧТО НУЖНО В ПРОЕКТЕ
  • Unity 6, шаблон 2D (URP).
  • Пакет Input System (в шаблоне уже есть). Если при запуске красная ошибка про Input:
    Project Settings → Player → Active Input Handling = Input System Package (New) или Both.
  • TextMeshPro: при первом тексте Unity предложит Import TMP Essentials — согласиться.

УСТАНОВКА
  Распаковать архив в корень проекта (туда, где папка Assets), согласиться на замену.
  Ничего заранее не удалять — тогда настройки на объектах сохранятся.
  После компиляции вверху Unity появится меню KT. Если меню нет — в Console есть красная ошибка.

МЕНЮ KT
  • Справочник скриптов — за что отвечает каждый скрипт (то же видно вверху инспектора).
  • Мастер аниматора — собирает Animator из клипов или кадров. Для игрока и для врагов.
  • Уровни высоты — холмы с лестницами (вариант Б, бонус).
  • Проверить сцену — ищет типичные ошибки.
  • Создать экран победы — готовый экран «Уровень пройден!» с кнопками.

БЫСТРЫЙ СТАРТ
  Вариант А (платформер): игрок = Rigidbody 2D (Dynamic, Gravity Scale 3) + коллайдер + тег Player
                          + PlatformerMovement2D. Камера = CameraFollow2D.
  Вариант Б (вид сверху): игрок = Rigidbody 2D (Dynamic, Gravity Scale 0, Linear Damping 8,
                          Freeze Rotation Z) + коллайдер у ног + тег Player + TopDownMovement2D.
  Монета: Coin (Sprite Renderer, Rigidbody 2D, Circle Collider 2D)
          └─ PickupZone (Circle Collider 2D Is Trigger, побольше) + CoinPickup.
  Счётчик: CoinCounter на Canvas + текст TextMeshPro в поле Label.

ЕСЛИ ЧТО-ТО НЕ ТАК
  • Всё или часть спрайтов чёрные → Global Light 2D → Target Sorting Layers → All.
  • Меню KT не появилось → исправить красные ошибки в Console.
  • Сначала — KT → Проверить сцену.

ПАПКИ
  0_Core      служебное, ни на что не вешается
  1_Player    игрок: движение, анимация, удар, жизни
  2_Coins     монеты, счётчик, сундук
  3_Level     платформы, двери, шипы, смертельная зона, телепорты, чекпоинты, лестницы
  4_Enemies   враги и всё, что можно ударить
  5_Triggers  «зашёл — сработало», «подошёл и нажал E»
  6_Camera    камера и параллакс
  7_UI        перезапуск, пауза, таймер, экран победы
  Editor      меню KT (в игру не попадает)
